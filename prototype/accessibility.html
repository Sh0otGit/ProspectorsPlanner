Accessibility

Prospector's Planner is not a UTEP service, so ADA Title II's rules for public entities don't directly bind it — but it's built for UTEP students, so accessibility is the bar regardless.

Last updated August 18, 2026.

Target

This site targets WCAG 2.1 Level AA: content that's perceivable, operable by keyboard, understandable, and robust across browsers and assistive technology. That's a target being worked toward, not a claim of full conformance today.

What's already in place

  • Colorblind-safe rating colors, checked for contrast separation rather than eyeballed — see the labeled legend under every rating bar, which exists specifically because color alone isn't a safe encoding.
  • Interface text kept to real, semantic HTML rather than images of text.
  • Layouts checked at narrow widths (430px) for horizontal overflow, which breaks keyboard and screen-magnifier navigation alike.

Known gaps

This is a working prototype. Full keyboard-navigation and screen-reader passes on the availability grid and the schedule's overlap-highlighting interaction haven't been completed yet, and some interactive elements may not yet have complete ARIA labeling. These are being worked through, not ignored.

Report a barrier

If something on this site is difficult or impossible to use with a keyboard, screen reader, or other assistive technology, use Report a problem and describe what happened. Accessibility reports are treated as bugs, not feature requests.
